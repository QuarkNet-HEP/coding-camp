# Coding Camp


Coding Camp is a introduction to Python and data analysis using real scientific data. Camps are offered both online as well as in person at QuarkNet Centers.


## What this site is for
- Help teachers find already created Python notebooks to be used or modified in their classes
- Provide examples of notebooks for how to incorporate coding concepts into an existing curriculum
